# DEATH MODE v2 — user_data 디렉토리 구조

이 디렉토리는 Freqtrade 봇의 모든 런타임 데이터를 저장합니다.
Docker 컨테이너의 `/freqtrade/user_data` 로 마운트됩니다.

---

## 📁 디렉토리 설명

### `strategies/`
NFI(NostalgiaForInfinity) 전략 Python 파일이 위치하는 폴더입니다.
- `nfi-updater` 사이드카 컨테이너가 주기적으로 최신 파일을 자동 갱신합니다.
- 수동으로 커스텀 전략을 추가할 수도 있습니다.
- 주요 파일: `NostalgiaForInfinityX7.py`, `NostalgiaForInfinityX8.py` 등

### `data/`
거래소에서 다운로드한 OHLCV 캔들 데이터가 저장됩니다.
- 백테스트 / 하이퍼옵트 실행 전 `freqtrade download-data` 명령으로 데이터를 먼저 받아야 합니다.
- 서브 디렉토리: `binanceusdm/`, `bybit/`, `bitget/`, `okx/` 등 거래소별로 분리됩니다.

### `logs/`
Freqtrade 봇의 실시간 로그가 기록됩니다.
- `freqtrade.log` — 주 봇 로그 (최대 50MB × 5개 롤오버)
- 장애 분석, 포지션 추적에 활용하세요.

### `backtest_results/`
백테스트 및 하이퍼옵트 실행 결과 JSON 파일이 저장됩니다.
- FreqUI 또는 `freqtrade backtesting-show` 명령으로 조회 가능합니다.
- 결과 파일은 실행 타임스탬프로 자동 명명됩니다.

## 🚀 빠른 시작

```bash
# 1. 전략 파일 수동 갱신 (nfi-updater 사이드카가 자동으로 처리)
docker compose run --rm nfi-updater

# 2. 데이터 다운로드 (백테스트용)
docker compose run --rm freqtrade download-data \
  --config /freqtrade/config/binance_futures.json \
  --timerange 20240101-

# 3. 백테스트 실행
docker compose run --rm freqtrade backtesting \
  --config /freqtrade/config/binance_futures.json \
  --strategy NostalgiaForInfinityX7 \
  --timerange 20240101-20241231

# 4. 봇 라이브 실행
docker compose up -d
```
